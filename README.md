# AI-Resume-ATS-Screening-System
 🤖 AI-Based Resume Screening & ATS Recruitment System

An AI-powered Applicant Tracking System (ATS) that analyzes resumes, extracts candidate information, matches skills with job requirements, and generates an ATS compatibility score.

📌 Project Overview

The AI-Based Resume Screening & ATS Recruitment System helps recruiters reduce manual resume screening by automatically analyzing candidate resumes against a given job description.

The system identifies relevant skills and qualifications, calculates an ATS matching score, and supports candidate shortlisting based on job requirements.

🚀 Key Features

- 📄 Resume PDF processing
- 🤖 AI/NLP-based resume analysis
- 🎯 ATS matching score
- 🔍 Skill and qualification extraction
- 📊 Candidate screening dashboard
- ✅ Candidate shortlisting
- ❌ Identification of unsuccessful applicants
- 🗄️ Database storage
- 🌐 Flask-based web application
- 📈 Recruitment analytics
